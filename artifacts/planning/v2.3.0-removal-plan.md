# v2.3.0 - Legacy Code Removal Plan

**Purpose:** Remove deprecated features deferred from v2.2.0
**Target:** Q1 2026 (3 months after v2.2.0 release)
**Type:** Breaking changes with migration path

---

## What Was Deferred from v2.2.0

During v2.2.0 implementation audit (2025-10-20), we discovered that removing `/save-context` would require updating 200+ files across documentation. To avoid massive churn and potential breakage, we deferred removal to v2.3.0.

**Audit Findings:**
- `/save-context` references: 150+ across all docs
- `save-context-helper.sh`: Used by current `/save` and `/save-full` commands
- `save-context-guide.md`: 23K of documentation
- `QUICK_REF` references: 65 in templates

**Decision:** Mark as deprecated in v2.2.0, remove in v2.3.0

## Migration Guide Updates

### For Users

**v2.3.0 Migration:**
1. Update any scripts/workflows that call `/save-context`
2. Replace with `/save` (quick) or `/save-full` (comprehensive)
3. No data migration needed - just command rename

**Breaking Changes:**
- `/save-context` command removed (deprecated since v2.1)
- `save-context-helper.sh` removed (internal, shouldn't affect users)

### For Developers

**If you vendored the context system:**
1. Check if any custom commands call `save-context-helper.sh`
2. Update to use inline logic or `/save`/`/save-full` commands
3. Remove references from documentation

## Risk Assessment

### Low Risk
- Deleting `/save-context.md` - Already deprecated, users know to migrate
- Deleting `save-context-guide.md` - Docs consolidated into command files

### Medium Risk
- Deleting `save-context-helper.sh` - Need to verify `/save` and `/save-full` work without it
- Updating 200+ doc references - Could miss some, leaving stale links

### High Risk
- None - This is cleaning up already-deprecated features

### Mitigation
- 1 month warning period with loud deprecation notices
- Pre-removal testing in v2.2.5
- Thorough documentation sweep
- CHANGELOG clearly communicates changes
