# v6.0.2 Release Plan

## Overview

Patch release to fix v5.x → v6.0 migration issues. Clean break from legacy system.

## Philosophy

1. **`/save` does ONE thing** — Updates context in v6.0 format. Nothing else.
2. **`update-context-system` handles v6.x → v6.y upgrades** — For post-v6 systems only.
3. **`migrate-to-v6.sh` handles pre-v6 → v6.0 migration** — One-time bootstrap script.
4. **No tech debt** — Migrate everything to v6.0 format. Don't preserve old formats.
5. **Clean break** — After upgrade, zero v5.x artifacts remain.

---

## Two Upgrade Paths

| From | To | Method |
|------|-----|--------|
| Pre-v6 (v5.x, v4.x, etc.) | v6.0+ | Run `migrate-to-v6.sh` script (one-time) |
| v6.x | v6.y | Run `/update-context-system` command |

### Why Two Paths?

The pre-v6 `/update-context-system` command has script dependencies that break when v6.0 deletes them mid-execution. We can't fix deployed v5.x commands. A bootstrap script sidesteps this entirely.

---

## Problem Summary

Users upgrading from v5.x encounter failures:

| Issue | Cause |
|-------|-------|
| v5.x update command breaks | References scripts that v6.0 installer deletes |
| `/save` corrupts STATUS.md | Expects v6.0 format, destroys v5.x content |
| Version detection fails | Looks for `.claude/VERSION` which v5.x doesn't have |
| Mixed formats | v5.x DECISIONS.md format differs from v6.0 |

## Root Cause

When v5.x users run `/update-context-system`:
1. The v5.x command (with script dependencies) executes
2. v6.0 installer deletes `scripts/`, `templates/`, etc.
3. v5.x command breaks mid-execution
4. User left with v6.0 commands but v5.x context formats
5. `/save` fails or corrupts files

---

## Solution

### Principle: Separation of Concerns

| Component | Responsibility |
|-----------|----------------|
| `/save` | Update context. v6.0 format only. If v5.x format detected → error with clear guidance. |
| `/update-context-system` | v6.x → v6.y upgrades only. Downloads and installs latest v6.x commands. |
| `migrate-to-v6.sh` | Pre-v6 → v6.0 migration. One-time bootstrap script. Deletes itself after success. |

### `/save` Behavior

**If v5.x STATUS.md format detected:**
```
❌ STATUS.md is in v5.x format.

This project needs migration to v6.0. See MIGRATIONS.md for instructions:
https://github.com/rexkirshner/ai-context-system/blob/main/MIGRATIONS.md#upgrading-from-v5x

Do NOT run /update-context-system — it's for v6.x → v6.y upgrades only.
```

**Does NOT:**
- Migrate formats
- Clean artifacts
- Handle legacy edge cases

**ONLY:**
- Updates v6.0 format STATUS.md
- Records decisions to v6.0 format DECISIONS.md

### `/update-context-system` Behavior (v6.x → v6.y only)

For projects already on v6.0+:

1. **Verify v6.0+ format** — If v5.x detected, error with migration script guidance
2. **Download latest v6.x release**
3. **Update commands** in `.claude/commands/`
4. **Update VERSION** file
5. **Report success**

**Does NOT migrate pre-v6 systems.** That's what the migration script is for.

### `migrate-to-v6.sh` — Bootstrap Script

One-time script for pre-v6 → v6.0 migration. Lives in repo root, downloaded and run manually.

**What it does:**
1. **Backup everything** to `context-backup-YYYYMMDD/`
2. **Delete all v5.x artifacts** (scripts/, agents/, templates/, etc.)
3. **Download v6.0 commands** from GitHub
4. **Migrate STATUS.md** to v6.0 format (AI-assisted conversion)
5. **Migrate DECISIONS.md** to v6.0 format (condense to simple format)
6. **Delete itself** — it's not needed after migration
7. **Report success** with next steps

**Clear warnings in the script:**
```bash
# migrate-to-v6.sh
#
# ⚠️  ONE-TIME MIGRATION SCRIPT — Pre-v6 → v6.0 only
#
# DO NOT USE IF:
# - This is a fresh install (use /init-context instead)
# - You're already on v6.0+ (use /update-context-system instead)
#
# This script will DELETE ITSELF after successful migration.
```

## Changes for v6.0.2

### 1. Create `migrate-to-v6.sh` — Bootstrap Script

**File:** `migrate-to-v6.sh` (at repo root)

```bash
#!/bin/bash
#
# migrate-to-v6.sh — One-time migration from pre-v6 to v6.0
#
# ⚠️  DO NOT USE IF:
#     - This is a fresh install → use /init-context instead
#     - You're already on v6.0+ → use /update-context-system instead
#
# This script DELETES ITSELF after successful migration.
#

set -e

echo "═══════════════════════════════════════════════════════════"
echo "  AI Context System — Pre-v6 → v6.0 Migration"
echo "═══════════════════════════════════════════════════════════"
echo ""

# Check if already on v6.0
if [ -f ".claude/VERSION" ]; then
    VERSION=$(cat .claude/VERSION)
    if [[ "$VERSION" == 6.* ]]; then
        echo "❌ Already on v6.x ($VERSION)"
        echo ""
        echo "This script is for pre-v6 migrations only."
        echo "Use /update-context-system to upgrade from v6.x to v6.y."
        exit 1
    fi
fi

# Check if this is a fresh project (no v5.x artifacts)
if [ ! -d "scripts" ] && [ ! -d ".claude/agents" ] && [ ! -f "context/SESSIONS.md" ]; then
    echo "❌ No v5.x installation detected"
    echo ""
    echo "This script is for migrating existing v5.x installations."
    echo "For fresh installs, use /init-context instead."
    exit 1
fi

echo "✓ Detected pre-v6 installation"
echo ""

# 1. Backup
BACKUP_DIR="context-backup-$(date +%Y%m%d-%H%M%S)"
echo "📦 Creating backup in $BACKUP_DIR/"
mkdir -p "$BACKUP_DIR"
[ -d "context" ] && cp -r context "$BACKUP_DIR/"
[ -d ".claude" ] && cp -r .claude "$BACKUP_DIR/"
[ -f "CLAUDE.md" ] && cp CLAUDE.md "$BACKUP_DIR/"
echo "   ✓ Backup complete"
echo ""

# 2. Delete v5.x artifacts
echo "🗑️  Removing v5.x artifacts..."
rm -rf scripts/ templates/ config/ test/ reference/ artifacts/
rm -rf .claude/agents/ .claude/skills/ .claude/schemas/ .claude/hooks/ .claude/docs/
rm -f .claude/acs-settings.json .claude/.last-update-check
rm -f context/SESSIONS.md context/CONTEXT.md context/.context-config.json
rm -f context/cursor.md context/aider.md context/codex.md
rm -f context/generic-ai-header.md context/context-feedback.md
rm -rf docs/audits/ docs/skills/ docs/migration/ docs/archive/
rm -f install.sh VERSION
echo "   ✓ v5.x artifacts removed"
echo ""

# 3. Download v6.0 commands
echo "📥 Downloading v6.0 commands..."
git clone --depth 1 https://github.com/rexkirshner/ai-context-system.git /tmp/acs-migrate 2>/dev/null
rm -rf .claude/commands/
mkdir -p .claude
cp -r /tmp/acs-migrate/.claude/commands .claude/
cp /tmp/acs-migrate/.claude/VERSION .claude/
rm -rf /tmp/acs-migrate
echo "   ✓ v6.0 commands installed"
echo ""

# 4. Report STATUS.md and DECISIONS.md migration needed
echo "═══════════════════════════════════════════════════════════"
echo "  ⚠️  MANUAL STEPS REQUIRED"
echo "═══════════════════════════════════════════════════════════"
echo ""
echo "v6.0 commands are installed, but your context files need"
echo "manual migration to v6.0 format."
echo ""
echo "1. Restart Claude Code (exit and reopen)"
echo ""
echo "2. Ask Claude to migrate your context files:"
echo "   \"Please migrate context/STATUS.md and context/DECISIONS.md"
echo "    to v6.0 format. Backup is in $BACKUP_DIR/\""
echo ""
echo "STATUS.md v6.0 format:"
echo "   # Status"
echo "   SchemaVersion: 1"
echo "   LastUpdated: YYYY-MM-DD"
echo "   HeadCommit: [git SHA]"
echo "   Objective: [goal]"
echo "   ## Working Set"
echo "   ## Next Actions"
echo "   ## Blocked On"
echo ""
echo "DECISIONS.md v6.0 format:"
echo "   ## YYYY-MM-DD: [Area] Title"
echo "   Why: [reason]"
echo "   Tradeoff: [cost]"
echo "   RevisitWhen: [trigger]"
echo ""

# 5. Delete self
echo "🗑️  Removing migration script (no longer needed)..."
rm -f "$0"
echo "   ✓ Migration script removed"
echo ""
echo "═══════════════════════════════════════════════════════════"
echo "  Migration artifacts cleaned. Restart Claude Code now."
echo "═══════════════════════════════════════════════════════════"
```

### 2. Update `/save` — Add Format Guard

**File:** `.claude/commands/save.md`

Add at the beginning of execution:

```markdown
### Format Check

Before updating, verify `context/STATUS.md` is in v6.0 format.

**v6.0 format required indicators:**
- Contains `SchemaVersion: 1`
- Has `## Working Set` section
- Has `## Next Actions` section

**v5.x format indicators (migration needed):**
- Contains `## Quick Reference`
- Contains `## Current Phase` or `## Work In Progress`
- Has URL fields, Tech Stack sections
- Missing `SchemaVersion`

**If v5.x format detected:**

Stop and report:
```
❌ STATUS.md is in v5.x format.

This project needs migration to v6.0. See MIGRATIONS.md:
https://github.com/rexkirshner/ai-context-system/blob/main/MIGRATIONS.md#upgrading-from-v5x

Download and run the migration script:
curl -O https://raw.githubusercontent.com/rexkirshner/ai-context-system/main/migrate-to-v6.sh
chmod +x migrate-to-v6.sh
./migrate-to-v6.sh

Do NOT run /update-context-system — it's for v6.x → v6.y upgrades only.
```

Do NOT attempt to update the file.
```

## Upgrading from v5.x (or Earlier)

If you're on a pre-v6 version (v5.x, v4.x, etc.), you need to run the migration script.

You're on pre-v6 if you have any of:

### Migration Steps

   ```bash
   curl -O https://raw.githubusercontent.com/rexkirshner/ai-context-system/main/migrate-to-v6.sh

   ./migrate-to-v6.sh
   ```

3. **Ask Claude to migrate your context files:**
   The script installs v6.0 commands but leaves context file migration to Claude.

4. **Verify with /save**

### What the Script Does

- Creates backup in `context-backup-YYYYMMDD/`

- Downloads v6.0 commands from GitHub

### If Something Goes Wrong
