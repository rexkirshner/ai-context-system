## Priority 2: Fix Session Number Detection (10 min)

**Issue**: `/save-full` uses `grep -c "^## Session"` which counts occurrences, not max number. With gaps or archives, gives wrong results.

**Current code** (in save-full.md):
```bash
grep -c "^## Session" SESSIONS.md
```

**Fix**:
```bash
grep -oE "^## Session [0-9]+" SESSIONS.md | grep -oE "[0-9]+" | sort -n | tail -1
```

**Files to modify**:
- `.claude/commands/save-full.md`

## Priority 4: Fix Consistency Check Logic (20 min)

**Issue**: `/review-context` checks for fields in files where they don't belong:
- Looks for "Last Updated:" in SESSIONS.md (doesn't have this field)
- Looks for "Phase:" in CONTEXT.md (only exists in STATUS.md)

**Result**: False "not found" warnings confuse users

**Fix**: Update consistency check to only look for fields in appropriate files:

| Field | Should check in |
|-------|-----------------|
| Last Updated: | STATUS.md, CONTEXT.md |
| Phase: | STATUS.md only |
| Current Focus: | STATUS.md only |

**Files to modify**:
- `.claude/commands/review-context.md` - the bash grep commands in consistency check section

## Priority 5: Add Framework Pattern Notes (15 min)

**Issue**: Audit commands have React-specific patterns (dangerouslySetInnerHTML, useCallback) without mentioning Svelte/Vue equivalents.

**Fix**: Add framework alternatives in relevant audit commands:

| Concept | React | Svelte | Vue |
|---------|-------|--------|-----|
| Raw HTML injection | dangerouslySetInnerHTML | {@html} | v-html |
| Memoization | useMemo, useCallback | $derived | computed |
| Side effects | useEffect | $effect | watch |

**Files to modify**:
