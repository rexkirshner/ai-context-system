# v4.0.2 Action Plan

Based on user feedback from second v4.0.1 deployment (Project C).

## Priority 1: Add File Existence Detection to /save-full

**Source**: Feedback - /save-full references STATUS.md but project doesn't have one

**Problem**:
- Step 4 of /save-full instructs updating STATUS.md
- Projects may not have all context files (old installations, partial migrations, minimal setups)
- Command should gracefully handle missing files instead of confusing users

**Solution**:
Add file existence detection at the start of /save-full:

```bash
echo "📁 Detecting context files..."
HAS_CONTEXT=false
HAS_STATUS=false
HAS_DECISIONS=false
HAS_SESSIONS=false

test -f "$CONTEXT_DIR/CONTEXT.md" && HAS_CONTEXT=true && echo "  ✅ CONTEXT.md"
test -f "$CONTEXT_DIR/STATUS.md" && HAS_STATUS=true && echo "  ✅ STATUS.md"
test -f "$CONTEXT_DIR/DECISIONS.md" && HAS_DECISIONS=true && echo "  ✅ DECISIONS.md"
test -f "$CONTEXT_DIR/SESSIONS.md" && HAS_SESSIONS=true && echo "  ✅ SESSIONS.md"

# Warn about missing files
if [ "$HAS_STATUS" = false ]; then
  echo "  ⚠️ STATUS.md not found - will skip status updates"
  echo "     Run /init-context to create missing files"
fi
```

Then conditionally show steps based on which files exist.

**Files to modify**:
- `.claude/commands/save-full.md`

**Testing**:
1. Test with full context setup (all 4 files) - all steps should show
2. Test with missing STATUS.md - should skip Step 4 with warning
3. Test with missing SESSIONS.md - should warn (this is critical)
4. Test with only CONTEXT.md - should work with minimal steps
