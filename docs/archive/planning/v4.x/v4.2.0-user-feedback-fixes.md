## Phase 1: Bug Fixes

### Bug 1: save-full.md Step 1 Bash Precedence

**Location:** `.claude/commands/save-full.md` line 93

**Source:** User feedback - "All three conditions execute because `&&` has higher precedence than `||`"

**Current Code (broken):**
```bash
test -d "context" && echo "context" || test -d "../context" && echo "../context" || test -d "../../context" && echo "../../context" || echo "ERROR: context/ not found"
```

**Problem:** Parses as `((A && B) || (C && D)) || E` - multiple branches can execute.

**Fix:**
```bash
if [ -d "context" ]; then
  echo "context"
elif [ -d "../context" ]; then
  echo "../context"
elif [ -d "../../context" ]; then
  echo "../../context"
else
  echo "ERROR: context/ not found"
  echo ""
  echo "Run this command from your project root or a subdirectory (up to 2 levels deep)."
fi
```

**Checkpoint 1.1:**
- [ ] Edit save-full.md line 93
- [ ] Replace test/&&/|| chain with if-elif-else
- [ ] Commit: `fix(save-full): Fix bash operator precedence in context detection`

**Verification:**
```bash

# Should output "context" exactly once, no other messages
```

### Bug 2: save-full.md Step 3 Session Number Regex

**Location:** `.claude/commands/save-full.md` line 233

**Source:** User feedback - "Regex picks up Session Index heading and template placeholders"

**Current Code (broken):**
```bash
grep -oE "^## Session [0-9]+" "$CONTEXT_DIR/SESSIONS.md" 2>/dev/null | grep -oE "[0-9]+" | sort -n | tail -1 | awk '{print} END {if (NR==0) print "0"}'
```

**Problem:** Matches "## Session Index" heading and template examples like "## Session [N]".

**Fix:**
```bash
# Match actual session entries (format: "## Session N | DATE | TITLE")
grep -E "^## Session [0-9]+ \|" "$CONTEXT_DIR/SESSIONS.md" 2>/dev/null | grep -oE "Session [0-9]+" | grep -oE "[0-9]+" | sort -n | tail -1 | awk '{print} END {if (NR==0) print "0"}'
```

**Key change:** Added ` \|` to require the pipe separator that real session entries have.

**Checkpoint 1.2:**
- [ ] Edit save-full.md line 233
- [ ] Add ` \|` to regex pattern
- [ ] Commit: `fix(save-full): Fix session number regex to exclude template text`

**Verification:**
```bash
# Create test file:

echo "## Session 1 | 2026-01-07 | Test" >> /tmp/test-sessions.md
echo "## Session 2 | 2026-01-07 | Test" >> /tmp/test-sessions.md
```

### Bug 3: review-context.md Misleading Date Warning

**Location:** `.claude/commands/review-context.md` line 531

**Source:** User feedback - "CONTEXT.md vs STATUS.md date mismatch is EXPECTED behavior, not an issue"

**Current Code (misleading):**
```bash
echo "  ⚠️  Date mismatch: CONTEXT.md ($CONTEXT_DATE) vs STATUS.md ($STATUS_DATE)"
echo "      STATUS.md is typically more current. Run /save to sync."
```

**Problem:** Different dates are BY DESIGN:
- CONTEXT.md is "static layer" - updated rarely (architecture changes)
- STATUS.md is "dynamic layer" - updated every session

**Fix:**
```bash
echo "  ℹ️  Layer dates: CONTEXT.md ($CONTEXT_DATE) | STATUS.md ($STATUS_DATE)"
echo "      Note: Different dates are normal. CONTEXT.md is static, STATUS.md is dynamic."
```

**Checkpoint 1.3:**
- [ ] Edit review-context.md around line 531
- [ ] Change ⚠️ to ℹ️
- [ ] Remove "Run /save to sync" suggestion
- [ ] Add explanatory note about static vs dynamic layers
- [ ] Commit: `fix(review-context): Change misleading date warning to informational note`

**Verification:** Run `/review-context` on project where CONTEXT.md is older than STATUS.md. Should show ℹ️ info icon, not ⚠️ warning.

## Phase 2: Improvements

### Improvement 1: "Already Initialized" Detection

**Files to modify:**
- `.claude/commands/init-context.md`
- `.claude/commands/migrate-context.md`

**Source:** User feedback - "Neither command handled the 'already partially initialized' state well"

**Problem:** User ran /init-context, then /migrate-context. The context/ folder already had files, causing confusion.

**Fix:** Add detection step at start of both commands (after existing Step 0.x steps):

```bash
# Step 0.7: Check for existing initialization
echo "Checking for existing ACS installation..."
echo ""

if [ -f "context/.context-config.json" ]; then
  echo "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
  echo "⚠️  AI Context System Already Initialized"
  echo "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
  echo ""
  echo "Found: context/.context-config.json"
  echo ""
  echo "Existing context files:"
  ls context/*.md 2>/dev/null | head -10
  echo ""
fi
```

**AI Instructions (add to command):**
```markdown
**If context/.context-config.json exists:**

Present options to user:
1. **Continue anyway** - Augment existing installation (add missing files)
2. **Reset and start fresh** - Back up existing to .archive/context-backup-TIMESTAMP/
3. **Cancel** - Exit without changes

Wait for user selection before proceeding.
```

### Improvement 2: Existing CLAUDE.md Detection and Guidance

**Files to modify:**
- `.claude/commands/init-context.md`
- `.claude/commands/migrate-context.md`

**Source:** User feedback - "Project already had comprehensive CLAUDE.md (19KB). Created uncertainty about how ACS should integrate."

**Fix:** Add detection step (after Step 0.7):

```bash
# Step 0.8: Detect existing CLAUDE.md
if [ -f "CLAUDE.md" ]; then
  CLAUDE_SIZE=$(wc -c < CLAUDE.md | tr -d ' ')

  # Format size for display (cross-platform)
  if [ "$CLAUDE_SIZE" -gt 1048576 ]; then
    SIZE_DISPLAY="$(( CLAUDE_SIZE / 1048576 ))MB"
  elif [ "$CLAUDE_SIZE" -gt 1024 ]; then
    SIZE_DISPLAY="$(( CLAUDE_SIZE / 1024 ))KB"
  else
    SIZE_DISPLAY="${CLAUDE_SIZE}B"
  fi

  if [ "$CLAUDE_SIZE" -gt 5000 ]; then
    echo ""
    echo "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
    echo "📄 Existing CLAUDE.md Detected ($SIZE_DISPLAY)"
    echo "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
    echo ""
    echo "Your project has a comprehensive CLAUDE.md at the project root."
    echo "This file is auto-loaded by Claude Code at conversation start."
    echo ""
    echo "ACS Integration Strategy:"
    echo "  ✅ CLAUDE.md stays at project root (auto-loaded, primary reference)"
    echo "  ✅ ACS adds context/ folder with session state:"
    echo "     • STATUS.md - Current tasks, blockers, next steps"
    echo "     • SESSIONS.md - Session history with mental models"
    echo "     • DECISIONS.md - Decision log with rationale"
    echo "  ✅ CONTEXT.md will be lightweight, referencing CLAUDE.md"
    echo ""
    echo "Your CLAUDE.md remains the primary project documentation."
    echo "ACS supplements it with session continuity features."
    echo ""
  else
    echo "ℹ️  Found CLAUDE.md ($SIZE_DISPLAY) - will preserve at project root"
  fi
fi
```

**Note:** Uses arithmetic for size formatting (cross-platform) instead of `numfmt` (GNU-only).
