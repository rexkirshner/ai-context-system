# v4.1.0 Action Plan

Proactive CLAUDE.md health checking to prevent drift from CONTEXT.md.

## Problem Statement

CLAUDE.md is created once during `/init-context` and never automatically updated. Over time, as the project evolves and CONTEXT.md is updated, CLAUDE.md becomes stale. This means the "auto-loaded" context that Claude Code sees at every conversation start may be outdated, leading to:

- AI operating with wrong tech stack assumptions
- Outdated URLs being referenced
- Stale architectural patterns being followed
- Project identity/purpose drift

## Solution Overview

Add CLAUDE.md health checks to `/review-context` and `/save-full` that:
1. Compare CLAUDE.md against CONTEXT.md
2. Detect potential drift
3. Make specific recommendations on what needs updating

## What to Compare

### High-Value Comparisons

| Field | Detection Method | Why It Matters |
|-------|------------------|----------------|
| **Tech Stack** | Extract technology keywords from both files | AI may use wrong frameworks/libraries |
| **URLs** | Extract http/https URLs from both files | AI may reference wrong environments |
| **Project Name** | Look for project name patterns | AI may be confused about project identity |
| **Last Modified** | File timestamps | General staleness indicator |

### Tech Stack Keywords to Extract

Common technologies to look for:
- Frameworks: Next.js, React, Vue, Svelte, Remix, Astro, Express, FastAPI, Django
- Languages: TypeScript, JavaScript, Python, Go, Rust
- Databases: PostgreSQL, MySQL, MongoDB, SQLite, Redis, Prisma, Drizzle
- Infrastructure: Vercel, AWS, Cloudflare, Docker, Kubernetes
- Testing: Jest, Vitest, Playwright, Cypress

### URL Patterns

Extract URLs matching:
- Production: `https://` URLs (excluding github.com)
- Repository: `github.com`, `gitlab.com`
- Documentation: Common doc domains

### Priority 4: Test Suite

**What:** Create test script for CLAUDE.md health check.

**Location:** `scripts/tests/test-claude-md-check.sh`

**Test Cases:**

1. **Both files in sync** - No warning
   - Same tech stack keywords
   - Same URLs
   - Similar modification dates

2. **CLAUDE.md older than CONTEXT.md** - Staleness warning
   - CLAUDE.md 30+ days older
   - Should warn about potential staleness

3. **Tech stack mismatch** - Drift warning
   - CONTEXT.md has "Drizzle, Svelte"
   - CLAUDE.md only has "Prisma, React"
   - Should list missing technologies

4. **URL mismatch** - Drift warning
   - Different production URLs
   - Should flag URL discrepancy

5. **CLAUDE.md missing** - Creation suggestion
   - Only CONTEXT.md exists
   - Should suggest /add-ai-header claude

6. **CONTEXT.md missing** - Graceful skip
   - Only CLAUDE.md exists
   - Should skip check (can't compare)

7. **Neither file exists** - Graceful skip
   - Should skip check entirely

## Thresholds and Tuning

### Staleness Threshold
- **Green:** CLAUDE.md modified within 14 days of CONTEXT.md
- **Yellow:** CLAUDE.md 15-30 days older than CONTEXT.md
- **Red:** CLAUDE.md 30+ days older than CONTEXT.md

### Tech Stack Comparison
- Only flag technologies found in CONTEXT.md but NOT in CLAUDE.md
- Don't flag the reverse (CLAUDE.md may have intentional extras)
- Require at least 2 missing technologies to flag (avoid single-word false positives)

### URL Comparison
- Only compare production/staging URLs (not localhost, not github)
- Flag if URL exists in one file but not the other

---

## Edge Cases

### User has intentionally minimal CLAUDE.md
Some users may prefer a minimal CLAUDE.md. The check should:
- Not be blocking (just informational)
- Be easy to ignore
- Not spam on every run if nothing changed

### CLAUDE.md has extra content not in CONTEXT.md
This is expected (CLAUDE.md has rules, preferences, etc.). Only flag:
- Tech stack in CONTEXT.md missing from CLAUDE.md
- URLs in CONTEXT.md missing from CLAUDE.md

### Project doesn't use CONTEXT.md
If CONTEXT.md doesn't exist, skip the comparison entirely. Don't error.

## Future Enhancements (Not in v4.1.0)

### Auto-Update CLAUDE.md
Could offer to automatically update specific sections of CLAUDE.md based on CONTEXT.md. Deferred because:
- CLAUDE.md is meant to be user-customized
- Auto-updating could overwrite intentional customizations
- Better to recommend and let user decide

### Semantic Comparison
Could use more sophisticated comparison (embeddings, etc.). Deferred because:
- Keyword matching is good enough for obvious drift
- Keeps the system simple and fast
- No external dependencies
