---

### 2.2 Understand the review-context.md Context

**Objective:** Understand why grep -c was used and what the correct fix is.

**Read the context:**
```bash
sed -n '735,750p' .claude/commands/review-context.md
```

**Current code (line 739):**
```bash
SESSION_COUNT=$(grep -cE "^## Session [0-9]+" "$CONTEXT_DIR/SESSIONS.md" 2>/dev/null || echo "0")
```

**Analysis:**
- This counts total sessions (for display: "Total sessions documented: X")
- The function `get_max_session_number()` returns the highest number, not count
- For display purposes, counting is actually correct IF no gaps exist
- However, with gaps (1,2,3,8,9), count=5 but max=9

**Decision:** For "Total sessions documented" display, we actually want COUNT (how many entries), not MAX (highest number). But we should clarify the label.

**Options:**
1. Keep grep -c for count, but label clearly: "Sessions in file: N"
2. Use max_session_number and label: "Latest session number: N"
3. Show both: "N sessions documented (latest: Session M)"

**Recommendation:** Option 3 provides the most useful information.

**Checkpoint:**
- [ ] Decided on approach
- [ ] Approach provides more useful info than current

---

### 2.3 Implement the Fix

**Location:** `.claude/commands/review-context.md` around line 739

**Change from:**
```bash
SESSION_COUNT=$(grep -cE "^## Session [0-9]+" "$CONTEXT_DIR/SESSIONS.md" 2>/dev/null || echo "0")
echo "  Total sessions documented: $SESSION_COUNT"
```

**Change to:**
```bash
# Source common functions if not already sourced
if ! type get_max_session_number &>/dev/null; then
  REPO_ROOT=$(git rev-parse --show-toplevel 2>/dev/null || pwd)
  source "$REPO_ROOT/scripts/common-functions.sh" 2>/dev/null || true
fi

# Get both count and max for complete picture
SESSION_COUNT=$(grep -cE "^## Session [0-9]+" "$CONTEXT_DIR/SESSIONS.md" 2>/dev/null || echo "0")
MAX_SESSION=$(get_max_session_number "$CONTEXT_DIR" 2>/dev/null || echo "0")

echo "  Sessions in file: $SESSION_COUNT"
if [ "$SESSION_COUNT" != "$MAX_SESSION" ] && [ "$MAX_SESSION" != "0" ]; then
  echo "  Latest session: #$MAX_SESSION (some sessions may be archived)"
fi
```

**Why this is better:**
- Uses common function for max calculation
- Shows both count and max when they differ (indicates gaps)
- Provides context when sessions are archived
- Graceful fallback if function unavailable

**Checkpoint:**
- [ ] Code changed in review-context.md
- [ ] Verification: `grep -A5 "Sessions in file" .claude/commands/review-context.md`

## Phase 4: Bash Block Clarity (DOC-001)

### 4.1 Define the Standard

**Problem:** Command files mix:
1. Bash code meant to be executed
2. Bash code showing logic/algorithms (don't execute)
3. Example output (not code)

**Standard to implement:**

For code to execute:
```markdown
**Execute this:**
```bash
# Actual command to run
wc -l < context/SESSIONS.md
```
```

For logic explanation (do NOT execute):
```markdown
**Logic** (for understanding, do not execute):
```bash
# This is pseudocode explaining the algorithm
if [ some_condition ]; then
  # explanation of what happens
fi
```
```

For example output:
```markdown
**Example output:**
```
Session 12 created successfully
Files updated: 3
```
```

**Checkpoint:**
- [ ] Standard defined

### 4.5 Document the Standard

**Location:** `.claude/docs/command-philosophy.md` (add section)

**Add:**
```markdown
## Bash Block Labeling Standard

Command files contain three types of bash blocks:

### 1. Executable Code

Code that should be run. Always labeled:

```markdown
**Execute this:**
```bash
actual_command here
```
```

### 2. Logic Explanation

Pseudocode explaining algorithms. Never run directly:

```markdown
**Logic** (for understanding, do not execute):
```bash
# Explains what the code does conceptually
```
```

### 3. Example Output

Shows what output looks like. Not code:

```markdown
**Example output:**
```
Expected output here
```
```

This prevents AI agents from accidentally executing explanatory code.
```

**Checkpoint:**
- [ ] Standard documented in command-philosophy.md
- [ ] Future contributors can follow it
