## Critical Bugs

### BUG-001: Session Date Regex Only Matches `|` Separator

**Severity:** Critical
**Reported By:** Input Atlas
**Affects:** `/review-context` Step 2.8

**Problem:** Session header regex `^## Session [0-9]+ \|` only matches pipe separator, but some sessions use dash separator:
```markdown
## Session 1 | 2025-11-23 | Phase 0    <!-- Matches -->
## Session 17 - 2025-12-19             <!-- Doesn't match -->
```

**Impact:** Shows wrong "107 days ago" when most recent session uses `-` format.

**Fix Location:** `.claude/commands/review-context.md` - Step 2.8

**Solution:**
```bash
# Old:
grep -E "^## Session [0-9]+ \|"

# New:
grep -E "^## Session [0-9]+ [|\-]"
```

**Verification:**
```bash
# Test both formats match
echo "## Session 1 | 2025-11-23" | grep -E "^## Session [0-9]+ [|\-]"
echo "## Session 17 - 2025-12-19" | grep -E "^## Session [0-9]+ [|\-]"
# Both should output the line
```

**Effort:** 5 minutes

### BUG-002: zsh Math Expression Error in Config Health Check

**Severity:** Critical
**Reported By:** All 3 projects
**Affects:** `/review-context` Step 2.9

**Problem:** `grep -c` output includes trailing newline that breaks zsh arithmetic:
```bash
TBD_COUNT=$(grep -c '"TBD"' "$CONFIG_FILE" 2>/dev/null || echo "0")
TOTAL=$((TBD_COUNT + EMPTY_COUNT))  # Error: bad math expression
```

**Impact:** Config health check crashes with "operator expected" error.

**Fix Location:** `.claude/commands/review-context.md` - Step 2.9

**Solution:**
```bash
# Option A: Strip newlines
TBD_COUNT=$(grep -c '"TBD"' "$CONFIG_FILE" 2>/dev/null | tr -d '\n' || echo "0")

# Option B: Use default value expansion (preferred)
TBD_COUNT=$(grep -c '"TBD"' "$CONFIG_FILE" 2>/dev/null || true)
TBD_COUNT=${TBD_COUNT:-0}
```

**Verification:**
```bash
# Test in zsh
zsh -c 'COUNT=$(echo "0" | tr -d "\n"); echo $((COUNT + 1))'
# Should output: 1
```

**Effort:** 10 minutes

## Moderate Bugs

### BUG-003: CLAUDE.md Case Sensitivity Check

**Severity:** Moderate
**Reported By:** Input Atlas
**Affects:** `/update-context-system` Step 5.5

**Problem:** Script checks for `context/claude.md` (lowercase) but file is `context/CLAUDE.md` (uppercase).

**Impact:** Works on case-insensitive filesystems (macOS HFS+) by accident, would fail on Linux.

**Fix Location:** `.claude/commands/update-context-system.md` - Step 5.5

**Solution:**
```bash
# Old:
OLD_CLAUDE="context/claude.md"

# New:
OLD_CLAUDE="context/CLAUDE.md"
```

**Effort:** 2 minutes

### BUG-004: Duplicate Checkmarks in log_success Output

**Severity:** Moderate
**Reported By:** Kex Financial Tracker, Recap
**Affects:** Multiple commands using `log_success`

**Problem:** `log_success` prepends "✅ " but callers also include "✅ " in message:
```
✅ ✅ Archived feedback to artifacts/feedback/...
```

**Fix Location:** `scripts/common-functions.sh` - `log_success` function

**Solution:**
```bash
log_success() {
  local msg="$1"
  # Strip leading checkmark if present
  msg="${msg#✅ }"
  echo -e "${GREEN}✅ ${msg}${NC}"
}
```

**Effort:** 10 minutes

### BUG-005: Staleness Thresholds Not Read from Config

**Severity:** Moderate
**Reported By:** Recap
**Affects:** `/review-context` Step 2.7

**Problem:** Staleness check uses hardcoded 7/14 day thresholds instead of reading from `.context-config.json`:
```json
"CONTEXT.md": { "green": 90, "yellow": 180, "red": 365 }
```

**Impact:** CONTEXT.md at 18 days shows 🔴 when config says 90 days is 🟢.

**Fix Location:** `.claude/commands/review-context.md` - Step 2.7

**Solution:**
```bash
# Read threshold from config, default to hardcoded if not found
GREEN_THRESHOLD=$(jq -r ".validation.stalenessThresholds[\"$FILENAME\"].green // 7" "$CONFIG_FILE" 2>/dev/null)
GREEN_THRESHOLD=${GREEN_THRESHOLD:-7}
```

**Effort:** 15 minutes

### BUG-006: Archive Message Shows When No Archive Exists

**Severity:** Moderate
**Reported By:** Kex Financial Tracker
**Affects:** `/review-context` Step 2.8

**Problem:** Shows "some sessions may be archived" even when no `.sessions-archive/` directory exists.

**Impact:** Confusing message for projects that have gaps from deleted (not archived) sessions.

**Fix Location:** `.claude/commands/review-context.md` - Step 2.8

**Solution:**
```bash
if [ "$MAX_SESSION" -gt "$SESSION_COUNT" ]; then
  if [ -d "$CONTEXT_DIR/.sessions-archive" ] && [ "$(ls -A "$CONTEXT_DIR/.sessions-archive" 2>/dev/null)" ]; then
    echo "  Latest session: #$MAX_SESSION (some sessions archived)"
  else
    echo "  Latest session: #$MAX_SESSION (gaps in numbering)"
  fi
fi
```

**Effort:** 5 minutes
