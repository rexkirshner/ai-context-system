```bash
# Step 0: Find project root
# Navigate to project root if running from subdirectory
if [ ! -f "context/.context-config.json" ]; then
  # Try to find context folder in parent directories
  SEARCH_DIR="$PWD"
  FOUND_ROOT=""
  for i in 1 2 3; do
    SEARCH_DIR=$(dirname "$SEARCH_DIR")
    if [ -f "$SEARCH_DIR/context/.context-config.json" ]; then
      FOUND_ROOT="$SEARCH_DIR"
      break
    fi

  if [ -n "$FOUND_ROOT" ]; then
    echo "📁 Found project root: $FOUND_ROOT"
    cd "$FOUND_ROOT"
  else
    echo "❌ Error: No context/.context-config.json found"
    echo "   Run from project root or a subdirectory within 3 levels"
    exit 1
  fi
fi
```

### 3.2 Add extract_changelog_section() Function

**Location:** `scripts/common-functions.sh`

```bash
# Extract changelog section for a specific version
# Usage: extract_changelog_section "5.1.0" "CHANGELOG.md"
# Returns: Bullet points for that version (max 7)
extract_changelog_section() {
  local version="$1"
  local changelog="$2"

  if [ ! -f "$changelog" ]; then
    return 1
  fi

  # Find version section and extract bullets
  awk -v ver="$version" '
    /^## \[/ { if (found) exit; if (index($0, ver)) found=1; next }
    found && /^- / { if (count++ < 7) print }
  ' "$changelog"
}
```

**Acceptance Criteria:**
- [ ] Function added to common-functions.sh
- [ ] Returns max 7 bullet points
- [ ] Returns empty if version not found

**Verification:**

```bash
# Should show bullets
```

#### 4A.2 Define Deduplication Rules

**When are findings considered duplicates?**

1. **Same file + overlapping lines** (within 5 lines)
2. **Same function name mentioned**
3. **Same root pattern** (e.g., "N+1 query" in DB and PERF)

**Primary finding selection:**
- Higher severity wins
- Earlier agent alphabetically breaks ties

**Acceptance Criteria:**
- [ ] Deduplication rules documented
- [ ] Edge cases identified

```
  A: 90-100
  B: 80-89
```

## Phase 5: FEAT-8 - Library Adoption Advisor Agent (4-6 hours)

A new specialist agent that scans code for opportunities to replace homegrown implementations with battle-tested libraries.

### 5.1 Create library-advisor.md Agent

**Location:** `.claude/agents/library-advisor.md`

**Agent Contract:**
```json
{
  "id": "library-advisor",
  "prefix": "LIB",
  "category": "modernization",
  "applicability": {
    "always": true
  },
  "focusAreas": [
    "reinvented-wheels",
    "outdated-patterns",
    "library-opportunities",
    "best-practices"
  ],
  "outputFormat": "audit-finding"
}
```

**What It Scans For:**

| Pattern | Homegrown Sign | Recommended Libraries |
|---------|---------------|----------------------|
| Date manipulation | Manual string formatting, timezone math | date-fns, dayjs, luxon |
| HTTP client | Custom fetch wrappers, retry logic | axios, ky, got |
| Validation | Manual if/else chains, regex checks | zod, yup, joi, valibot |
| State management | Custom pub/sub, global objects | zustand, jotai, redux-toolkit |
| Retry logic | Custom while loops with delays | p-retry, async-retry |
| Debounce/throttle | Custom setTimeout patterns | lodash-es, throttle-debounce |
| Deep clone | JSON.parse(JSON.stringify()) | structuredClone, lodash |
| UUID generation | Math.random() patterns | uuid, nanoid |
| Encryption/hashing | Custom implementations | crypto-js, bcrypt, argon2 |
| Query strings | Manual parsing/building | qs, query-string |
| Markdown parsing | Regex-based parsing | marked, remark, markdown-it |

**Anti-Patterns to Detect:**
- Hand-rolled authentication flows
- Custom ORM/query builders when Prisma/Drizzle exist
- Manual SQL sanitization instead of parameterized queries
- Custom test utilities when testing-library exists
- Bespoke form handling instead of react-hook-form/formik

**Acceptance Criteria:**
- [ ] Agent file created with contract block
- [ ] Pattern detection logic documented
- [ ] Library recommendations table included
