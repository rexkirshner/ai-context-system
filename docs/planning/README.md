# Planning Documents

Historical planning and design documents for the AI Context System.

These are kept for reference but are not part of the distributed system.

## Contents

- `V6-SIMPLIFIED.md` - Design spec for v6.0 (the current version)
- `v5.1/`, `v5.2/` - Planning docs for previous versions
- `future/` - Ideas for future versions
- `archive/` - Superseded proposals

## Note

These documents are **not copied** when you install the AI Context System. They live only in the source repository.
