### Task 1.1: Fix grep -c arithmetic in organize-docs

**Problem:** In zsh, when `grep -c` finds no matches, the command substitution returns an empty string, causing arithmetic to fail:

```bash
# This fails in zsh when grep finds no matches
count=$(($(grep -c "pattern" file)))
# Error: zsh: bad math expression: empty string
```

**File:** `.claude/commands/organize-docs.md`

**Solution:** Use `|| echo 0` fallback and ensure variable is numeric:

```bash
# Before (broken in zsh)
FILE_COUNT=$(($(grep -c "\.md$" file)))

# After (works in all shells)
FILE_COUNT=$(grep -c "\.md$" file 2>/dev/null || echo "0")
FILE_COUNT=$((FILE_COUNT + 0))  # Ensure numeric
```

**Verification:**
```bash
# Test in zsh
zsh -c '
  echo "no matches here" > /tmp/test.txt
  count=$(grep -c "NOTFOUND" /tmp/test.txt 2>/dev/null || echo "0")
  count=$((count + 0))
  [ "$count" -eq 0 ] && echo "PASS" || echo "FAIL: got $count"
  rm /tmp/test.txt
'
```

**Checkpoint 1.1:**
- [ ] All `grep -c` in organize-docs use `|| echo "0"` fallback
- [ ] Arithmetic operations protected with `+ 0`
- [ ] Script runs without error in zsh
- [ ] Script runs without error in bash

### Task 1.2: Fix $MV_CMD variable expansion

**Problem:** Variable assignment and expansion syntax can differ between shells when the variable contains spaces:

```bash
# This may fail in some shells
MV_CMD="git mv"
$MV_CMD source dest  # Word splitting issues
```

**File:** `.claude/commands/organize-docs.md`

**Solution:** Use a function instead of a variable for complex commands:

```bash
# Before (problematic)
if git rev-parse --git-dir > /dev/null 2>&1; then
  MV_CMD="git mv"
else
  MV_CMD="mv"
fi
$MV_CMD "$source" "$dest"

# After (robust)
move_file() {
  local source="$1"
  local dest="$2"

  if git rev-parse --git-dir > /dev/null 2>&1 && git ls-files --error-unmatch "$source" > /dev/null 2>&1; then
    # File is tracked by git, use git mv
    git mv "$source" "$dest"
  else
    # Not in git or file not tracked, use regular mv
    mv "$source" "$dest"
  fi
}

# Usage
move_file "$source" "$dest"
```

**Verification:**
```bash
# Test in zsh

  mkdir -p /tmp/mv-test
  echo "content" > /tmp/mv-test/file.txt

  move_file() {
    local source="$1"

    mv "$source" "$dest"
  }

  move_file /tmp/mv-test/file.txt /tmp/mv-test/moved.txt
  [ -f /tmp/mv-test/moved.txt ] && echo "PASS" || echo "FAIL"
  rm -rf /tmp/mv-test
'
```

### Task 2.1: Design new JSON export approach

**Current approach problems:**
- Awk parsing of markdown is fragile
- Stateful parsing (in_session, etc.) is error-prone
- Code block detection missing entirely

**New approach:**
- Use line-by-line bash processing
- Track code block state with simple flag
- More flexible pattern matching
- Generate JSON with proper escaping

**Design document (in code comments):**
```bash
# JSON Export Strategy (v5.0.2)

# 4. Flexible date parsing:
#    - Full: YYYY-MM-DD
#    - Partial: YYYY-MM
#    - Invalid: mark as "unknown"
#
# 5. JSON output:
#    - Proper escaping for special characters
#    - Valid JSON structure
#    - Include metadata (export date, session count)
```

### Task 2.2: Create session counting function

**File:** `scripts/export-sessions-json.sh`

**Problem:** Current count includes "Session Index", "Session Template", template examples.

**Solution:**
```bash
# Count actual sessions (not template sections)
#
# Usage:
#   count=$(count_actual_sessions "context/SESSIONS.md")
#
count_actual_sessions() {
  local file="$1"

  if [ ! -f "$file" ]; then
    echo "0"
    return 0
  fi

  # Get content before any template/example sections
  # Match only "## Session N" where N is a digit (not [N])
  # Exclude lines containing "Template", "Index", "[N]"
  sed -n '1,/^## \(Example\|Session Template\)/p' "$file" 2>/dev/null | \
    grep -E "^## Session [0-9]+" | \
    grep -v -i "Template" | \
    grep -v "Index" | \
    grep -v "\[N\]" | \
    wc -l | \
    tr -d ' '
}
```

### Task 2.3: Create code block aware parser

**File:** `scripts/export-sessions-json.sh`

**Problem:** Content inside markdown code blocks (```) is parsed as if it were real content.

**Solution:**
```bash
# Parse SESSIONS.md while respecting code blocks
#
# Usage:
#   parse_sessions "context/SESSIONS.md" | process_each_line
#
# Output format (one per line):
#   SESSION_START:number:date:title
#   SESSION_CONTENT:line
#   SESSION_END
#
parse_sessions_file() {
  local file="$1"
  local in_code_block=false
  local in_session=false
  local current_session=""

  # Stop before template/example sections
  local content
  content=$(sed -n '1,/^## \(Example\|Session Template\)/p' "$file" 2>/dev/null)

  while IFS= read -r line; do
    # Track code block state
    if [[ "$line" =~ ^\`\`\` ]]; then
      if [ "$in_code_block" = "true" ]; then
        in_code_block=false
      else
        in_code_block=true
      fi
      continue
    fi

    # Skip content inside code blocks
    if [ "$in_code_block" = "true" ]; then
      continue
    fi

    # Check for session header
    if [[ "$line" =~ ^##\ Session\ ([0-9]+) ]]; then
      # Close previous session if open
      if [ "$in_session" = "true" ]; then
        echo "SESSION_END"
      fi

      # Parse session header
      local session_num="${BASH_REMATCH[1]}"
      local date=""
      local title=""

      # Try pipe format: ## Session N | DATE | TITLE
      if [[ "$line" =~ \|\ ([0-9]{4}-[0-9]{2}(-[0-9]{2})?)\ \|\ (.+)$ ]]; then
        date="${BASH_REMATCH[1]}"
        title="${BASH_REMATCH[3]}"
      # Try pipe format without title: ## Session N | DATE
      elif [[ "$line" =~ \|\ ([0-9]{4}-[0-9]{2}(-[0-9]{2})?)$ ]]; then
        date="${BASH_REMATCH[1]}"
        title=""
      # Try dash format: ## Session N - DATE
      elif [[ "$line" =~ -\ ([0-9]{4}-[0-9]{2}(-[0-9]{2})?) ]]; then
        date="${BASH_REMATCH[1]}"
        title=""
      fi

      echo "SESSION_START:$session_num:$date:$title"
      in_session=true
      continue
    fi

    # Regular content line
    if [ "$in_session" = "true" ]; then
      echo "SESSION_CONTENT:$line"
    fi

  done <<< "$content"

  # Close final session
  if [ "$in_session" = "true" ]; then
    echo "SESSION_END"
  fi
}
```

**Verification:**

```markdown

### Task 2.4: Create JSON generator with proper escaping

**File:** `scripts/export-sessions-json.sh`

**Problem:** Special characters in content break JSON.

**Solution:**
```bash
# Escape string for JSON
#
# Usage:
#   escaped=$(json_escape "string with \"quotes\" and \\ backslashes")
#
json_escape() {
  local str="$1"
  # Escape backslashes first, then quotes, then control characters
  str="${str//\\/\\\\}"
  str="${str//\"/\\\"}"
  str="${str//$'\n'/\\n}"
  str="${str//$'\t'/\\t}"
  str="${str//$'\r'/\\r}"
  echo "$str"
}

# Generate JSON object for a session
#
# Usage:
#   generate_session_json 1 "2026-01-01" "Title" "TL;DR content" "Complete"
#
generate_session_json() {
  local num="$1"
  local date="$2"
  local title="$3"
  local tldr="$4"
  local status="$5"

  cat << EOF
{
  "sessionNumber": $num,
  "date": "$(json_escape "$date")",
  "title": "$(json_escape "$title")",
  "tldr": "$(json_escape "$tldr")",
  "status": "$(json_escape "$status")"
}
EOF
}
```

**Verification:**

### Task 2.5: Rewrite main export function

**File:** `scripts/export-sessions-json.sh`

**Complete rewrite of the main function:**

```bash
#!/bin/bash
# export-sessions-json.sh - Export SESSIONS.md to JSON format
#
# Version: See VERSION file
#
# Robust JSON export that handles:
# - Multiple session header formats (pipe and dash)
# - Markdown code blocks (skipped)
# - Partial dates (YYYY-MM accepted)
# - Template/example sections (excluded)
# - Special characters (properly escaped)

set -e

SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
if [ -f "$SCRIPT_DIR/common-functions.sh" ]; then
  source "$SCRIPT_DIR/common-functions.sh"
fi

# ... (include functions from Tasks 2.2, 2.3, 2.4) ...

# Main export function
export_sessions_to_json() {
  local context_dir="${1:-context}"
  local sessions_file="$context_dir/SESSIONS.md"
  local output_file="$context_dir/.sessions-data.json"

  if [ ! -f "$sessions_file" ]; then
    echo "Error: $sessions_file not found"
    return 1
  fi

  local total_sessions
  total_sessions=$(count_actual_sessions "$sessions_file")

  echo "Exporting $total_sessions sessions to JSON..."

  # Generate JSON
  {
    echo "{"
    echo '  "metadata": {'
    echo "    \"exportDate\": \"$(date +%Y-%m-%d)\","
    echo "    \"sourceFile\": \"$sessions_file\","
    echo "    \"totalSessions\": $total_sessions"
    echo '  },'
    echo '  "sessions": ['

    local first=true
    local current_num=""
    local current_date=""
    local current_title=""
    local current_tldr=""
    local current_status=""
    local in_tldr=false

    while IFS= read -r event; do
      case "$event" in
        SESSION_START:*)
          # Parse: SESSION_START:num:date:title
          IFS=':' read -r _ num date title <<< "$event"
          current_num="$num"
          current_date="$date"
          current_title="$title"
          current_tldr=""
          current_status="Complete"
          in_tldr=false
          ;;
        SESSION_CONTENT:*)
          local content="${event#SESSION_CONTENT:}"

          # Detect TL;DR section
          if [[ "$content" =~ ^###\ TL\;DR ]] || [[ "$content" =~ ^\*\*TL\;DR ]]; then
            in_tldr=true
            continue
          fi

          # Detect end of TL;DR (next section)
          if [ "$in_tldr" = "true" ] && [[ "$content" =~ ^### ]]; then
            in_tldr=false
          fi

          # Capture TL;DR content
          if [ "$in_tldr" = "true" ] && [ -n "$content" ]; then
            if [ -n "$current_tldr" ]; then
              current_tldr="$current_tldr $content"
            else
              current_tldr="$content"
            fi
          fi

          # Detect status
          if [[ "$content" =~ Status:.*In\ Progress ]] || [[ "$content" =~ ⏳ ]]; then
            current_status="In Progress"
          fi
          ;;
        SESSION_END)
          # Output session JSON
          if [ "$first" = "true" ]; then
            first=false
          else
            echo ","
          fi

          generate_session_json "$current_num" "$current_date" "$current_title" "$current_tldr" "$current_status" | sed 's/^/    /'
          ;;
      esac
    done < <(parse_sessions_file "$sessions_file")

    echo ""
    echo "  ]"
    echo "}"
  } > "$output_file"

  # Validate output
  if json_validate "$output_file" 2>/dev/null; then
    echo "✅ Valid JSON generated: $output_file"
    echo "   Sessions exported: $total_sessions"
    return 0
  else
    echo "❌ Invalid JSON generated"
    echo "   File: $output_file"
    return 1
  fi
}

# Run if called directly
if [[ "${BASH_SOURCE[0]}" == "${0}" ]]; then
  export_sessions_to_json "$@"
fi
```

### Task 3.1: Fix Current Focus extraction pattern

**Problem:** Script looks for `**In Progress:**` but real STATUS.md files use different formats like `## Active Tasks` or `**Next Priorities:**`.

**File:** `scripts/update-quick-reference.sh`

**Current (too specific):**
```bash
CURRENT_FOCUS=$(grep -A 2 "**In Progress:**" "$STATUS_FILE" | grep "^\- \[ \]" | head -1 | sed 's/^- \[ \] //')
```

**New (flexible cascade):**
```bash
# Extract current focus using multiple pattern fallbacks
#
# Tries in order:
# 1. **In Progress:** section with - [ ] items
# 2. **Next Priorities:** under ## Active Tasks
# 3. First unchecked - [ ] anywhere
# 4. ## Current Focus header content
#
extract_current_focus() {
  local file="$1"
  local focus=""

  # Try 1: **In Progress:** with unchecked items
  focus=$(grep -A 5 "\*\*In Progress:\*\*" "$file" 2>/dev/null | \
          grep "^\- \[ \]" | head -1 | sed 's/^- \[ \] //')
  if [ -n "$focus" ]; then
    echo "$focus"
    return 0
  fi

  # Try 2: **Next Priorities:** under Active Tasks
  focus=$(sed -n '/## Active Tasks/,/^## /p' "$file" 2>/dev/null | \
          grep -A 5 "\*\*Next Priorities:\*\*" | \
          grep "^\- " | head -1 | sed 's/^- //')
  if [ -n "$focus" ]; then
    echo "$focus"
    return 0
  fi

  # Try 3: First unchecked item anywhere
  focus=$(grep "^\- \[ \]" "$file" 2>/dev/null | head -1 | sed 's/^- \[ \] //')
  if [ -n "$focus" ]; then
    echo "$focus"
    return 0
  fi

  # Try 4: ## Current Focus section
  focus=$(sed -n '/^## Current Focus/,/^## /p' "$file" 2>/dev/null | \
          grep -v "^## " | grep -v "^$" | head -1)
  if [ -n "$focus" ]; then
    echo "$focus"
    return 0
  fi

  # Fallback
  echo "See STATUS.md"
}
```

**Verification:**
```bash

- [ ] Working on feature X
- [ ] Also doing Y
EOF

```
