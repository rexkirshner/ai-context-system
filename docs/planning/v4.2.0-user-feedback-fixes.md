### Bug 1: save-full.md Step 1 Bash Precedence

**Source:** User feedback - "All three conditions execute because `&&` has higher precedence than `||`"

**Problem:**
```bash
# Current (broken)
test -d "context" && echo "found here" || test -d "../context" && echo "found parent" || echo "not found"
# Parses as: ((A && B) || (C && D)) || E - all branches can execute
```

**Fix:**
```bash
# Correct
if [ -d "context" ]; then
  echo "✅ Found context/ in current directory"
  CONTEXT_DIR="context"
elif [ -d "../context" ]; then
  echo "⚠️  Found context/ in parent directory"
  CONTEXT_DIR="../context"
else
  echo "❌ No context/ directory found"
  exit 1
fi
```

**Checkpoint 1.1:**
- [ ] Locate the broken bash chain in save-full.md Step 1
- [ ] Replace with proper if-elif-else structure
- [ ] Test: Run from project root → should show "Found context/ in current directory" ONLY

- [ ] Test: Run with no context/ → should show not found and exit

**Verification:** Run `/save-full` from project root. Output should show exactly ONE context detection message.

### Bug 4: Missing days_since_file_modified Function

**Source:** User feedback - "Function doesn't exist or wasn't loaded"

**Problem:**
```bash
DAYS_OLD=$(days_since_file_modified "$file" 2>/dev/null || echo "-1")
# Function not defined in common-functions.sh
```

**Fix:** Add to scripts/common-functions.sh:
```bash
# Calculate days since file was last modified
# Usage: days_since_file_modified "/path/to/file"
# Returns: Integer number of days, or -1 if file doesn't exist
days_since_file_modified() {
  local file="$1"

  if [ ! -f "$file" ]; then
    echo "-1"
    return 1
  fi

  local file_mod now days

  # Cross-platform: macOS vs Linux stat syntax
  if [[ "$OSTYPE" == "darwin"* ]]; then
    file_mod=$(stat -f %m "$file" 2>/dev/null)
  else
    file_mod=$(stat -c %Y "$file" 2>/dev/null)
  fi

  # Fallback if stat fails
  if [ -z "$file_mod" ]; then
    echo "-1"
    return 1
  fi

  now=$(date +%s)
  days=$(( (now - file_mod) / 86400 ))

  echo "$days"
}
```

- [ ] Add `days_since_file_modified()` function to common-functions.sh
- [ ] Add test case to test suite
- [ ] Test on macOS: Create file, check days = 0
- [ ] Test on macOS: Touch file with old date, verify days calculation
- [ ] Test with non-existent file: Should return -1

**Verification:**
