### Root Cause Analysis

The bug affects BRE patterns that combine:
- `^` anchor at start of pattern
- Alternation with `\|`
- Special characters like `==` or `--` after the anchor

**Broken pattern:** `grep -v '^#\|^$\|^==\|^--'`
- Works: `'^#\|^$'` (simpler patterns)
- Fails: Adding `\|^==` causes BSD grep to misbehave

**Working patterns:** Those without `^` anchors or with simpler combinations work fine.

### Test Evidence

```bash
# Test file: /tmp/test-readme.md
# Project Title
================

A test description line.

## Features

# BRE pattern (broken):
$ grep -v '^#\|^$\|^==\|^--' /tmp/test-readme.md | head -1
# Result: '' (empty - gets blank line)

# ERE pattern (fixed):
$ grep -vE '^#|^$|^==|^--' /tmp/test-readme.md | head -1
# Result: 'A test description line.'
```

### Decision

1. **MUST FIX:** scripts/common-functions.sh:2194 - Breaks functionality
2. **SHOULD FIX:** Convert all BRE alternation to ERE for consistency and future-proofing
3. **Rationale:** ERE (`-E`) is more portable and readable; no downside to using it
