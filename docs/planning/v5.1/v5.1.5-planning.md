### 1.1 Same-Version Update Early Exit

**Issue:** BUG (Kex) - Running `/update-context-system` when already at latest version still downloads everything and creates backups.

**File:** `scripts/install.sh`

**Current behavior:**
```
Current version: 5.1.4 / New version: 5.1.4
Non-interactive mode: Proceeding with installation
[Full re-install occurs]
```

**Target behavior:**
```
Current version: 5.1.4
Latest version: 5.1.4
Already at latest version. No update needed.
```

**Implementation:**

```bash
# Add after version detection, before backup creation
if [ "$CURRENT_VERSION" = "$NEW_VERSION" ] && [ -n "$CURRENT_VERSION" ]; then
    echo ""
    echo "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
    echo "✅ Already at latest version ($NEW_VERSION)"
    echo "━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━"
    echo ""
    echo "No update needed. Your AI Context System is current."
    echo ""
    echo "To force reinstall: rm VERSION && /update-context-system"
    exit 0
fi
```

**Acceptance Criteria:**
- [ ] Same-version check added to install.sh
- [ ] Message clearly states no action taken
- [ ] Force reinstall option documented
- [ ] Exit code is 0 (success, not error)

**Verification:**

### 2.3 Respect noThreshold Config for DECISIONS.md

**Issue:** BUG (Journal Website) - DECISIONS.md flagged as stale despite `noThreshold: true` in config.

**File:** `.claude/commands/review-context.md`

**Current behavior:** Ignores config, applies standard staleness thresholds.

**Target behavior:** Reads config, skips staleness check for files with `noThreshold: true`.

**Implementation:**
```bash
# Read config to check for noThreshold files
NO_THRESHOLD_FILES=""
if [ -f "context/.context-config.json" ]; then
    # Extract files with noThreshold: true
    NO_THRESHOLD_FILES=$(grep -B5 '"noThreshold": true' context/.context-config.json | \
        grep -oE '"[A-Z]+\.md"' | tr -d '"' || echo "")
fi

# In staleness loop
if echo "$NO_THRESHOLD_FILES" | grep -q "$FILENAME"; then
    echo "  ℹ️  $FILENAME - Append-only (no staleness threshold per config)"
    continue
fi
```

### 2.4 Add "Time Since Last Session" to Report

**Issue:** SUGG-006 (NCL) - Shows date but not relative time.

**File:** `.claude/commands/review-context.md`

**Current:**
```
Last Session: Session 47 (2026-01-18)
```

**Target:**
```
Last Session: Session 47 (2026-01-18) - 5 days ago
```

**Implementation:**
```bash
# Calculate days since last session
LAST_SESSION_DATE="2026-01-18"  # Extracted from SESSIONS.md
TODAY=$(date +%Y-%m-%d)

# Cross-platform date diff
if [[ "$OSTYPE" == "darwin"* ]]; then
    LAST_EPOCH=$(date -j -f "%Y-%m-%d" "$LAST_SESSION_DATE" "+%s" 2>/dev/null || echo "0")
    TODAY_EPOCH=$(date "+%s")
else
    LAST_EPOCH=$(date -d "$LAST_SESSION_DATE" "+%s" 2>/dev/null || echo "0")
    TODAY_EPOCH=$(date "+%s")
fi

if [ "$LAST_EPOCH" != "0" ]; then
    DAYS_AGO=$(( (TODAY_EPOCH - LAST_EPOCH) / 86400 ))
    echo "Last Session: Session $SESSION_NUM ($LAST_SESSION_DATE) - $DAYS_AGO days ago"
fi
```

**Acceptance Criteria:**
- [ ] Days since last session calculated
- [ ] Works on both macOS and Linux
- [ ] Graceful fallback if date parsing fails

**Verification:**
