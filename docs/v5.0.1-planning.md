# v5.0.1 Release Planning Document

**Created:** 2026-01-14
**Based on:** Real-world feedback from v5.0.0 upgrades (NCL Website, Personal Website)
**Status:** Planning Complete - Ready for Implementation

---

## Executive Summary

v5.0.0 introduced the agent-based code review architecture, but the installer failed to download critical new directories. Additionally, several scripts have bugs that affect core functionality. This document outlines a systematic fix plan with incremental steps and verifiable checkpoints.

**Key Issues:**
- Installer missing 4 directories (agents, schemas, skills, hooks) - CRITICAL
- Session numbering uses COUNT instead of MAX - CRITICAL
- BSD awk incompatibility on macOS - HIGH
- Outdated command names in validation - HIGH
- Several moderate bugs in helper functions

**Approach:**
- Fix in phases, each with clear verification
- Embrace proper refactors over bandaids
- Add tests for each fix
- Ensure cross-platform compatibility

## Phase 2: Session Number Fix

**Goal:** `get_next_session_number()` returns MAX+1 instead of COUNT+1.

### Task 2.1: Rewrite get_next_session_number()

**What:** Change logic from counting sessions to finding maximum session number

**File:** `scripts/common-functions.sh` lines 826-849

**Current (broken):**
```bash
get_next_session_number() {
  local context_dir="${1:-context}"
  local sessions_file="$context_dir/SESSIONS.md"

  if [ ! -f "$sessions_file" ]; then
    echo "1"
    return 0
  fi

  # BUG: This COUNTS sessions, doesn't find MAX
  local count=$(sed -n '1,/^## Example/p' "$sessions_file" | \
                grep "^## Session [0-9]" | \
                grep -v "Template" | \
                wc -l | \
                tr -d ' ' || echo "0")

  echo $((count + 1))
}
```

**New (correct):**
```bash
# Get the next session number (MAX + 1, not COUNT + 1)
# Handles gaps from archiving and non-sequential session numbers
#
# Usage: get_next_session_number [context_dir]
# Returns: The next session number to use (MAX existing + 1)
#
# Example: If sessions 1,2,3,40,41,42 exist, returns 43 (not 7)
get_next_session_number() {
  local context_dir="${1:-context}"
  local sessions_file="$context_dir/SESSIONS.md"

  # No file = start at 1
  if [ ! -f "$sessions_file" ]; then
    echo "1"
    return 0
  fi

  # Find the maximum session number (not count)
  # Handles both formats: "## Session N |" and "## Session N -"
  # Excludes template sections after "## Example"
  local max_session=$(
    sed -n '1,/^## Example/p' "$sessions_file" 2>/dev/null | \
    grep -E "^## Session [0-9]+" | \
    grep -v "Template" | \
    sed -E 's/^## Session ([0-9]+).*/\1/' | \
    sort -n | \
    tail -1
  )

  # Default to 0 if no sessions found
  if [ -z "$max_session" ] || ! [[ "$max_session" =~ ^[0-9]+$ ]]; then
    max_session=0
  fi

  echo $((max_session + 1))
}
```

**Verification:**
```bash

cat > /tmp/test-sessions.md << 'EOF'
# Session History

## Session 44 | 2026-01-10 | Test
Content

## Session 43 | 2026-01-09 | Test
Content

## Session 5 | 2025-12-01 | Old
Content

## Example Session Format
Don't count this
EOF

source scripts/common-functions.sh
result=$(get_next_session_number /tmp)
[ "$result" = "45" ] && echo "PASS: Returns 45" || echo "FAIL: Returns $result, expected 45"
```

## Phase 3: Cross-Platform Compatibility

**Goal:** All scripts work on both macOS (BSD) and Linux (GNU).

### Task 3.1: Fix awk syntax in export-sessions-json.sh

**What:** Replace GNU awk `match($0, /pat/, arr)` with portable syntax

**File:** `scripts/export-sessions-json.sh` lines 106-107, 129+

**Current (GNU-only):**
```awk
match($0, /Session ([0-9]+)/, session_num)
match($0, /([0-9]{4}-[0-9]{2}-[0-9]{2})/, session_date)
# ... uses session_num[1], session_date[1]
```

**New (portable):**
```awk
# Extract session number
session_num = $0
sub(/^## Session /, "", session_num)
sub(/ .*/, "", session_num)

# Extract date (YYYY-MM-DD)
session_date = $0
gsub(/.*([0-9]{4}-[0-9]{2}-[0-9]{2}).*/, "\\1", session_date)
# Fallback: look for date pattern
if (session_date !~ /^[0-9]{4}-[0-9]{2}-[0-9]{2}$/) {
  # Try extracting from between | characters
  n = split($0, parts, "|")
  if (n >= 2) {
    session_date = parts[2]
    gsub(/^[ \t]+|[ \t]+$/, "", session_date)
  }
}
```

**Verification:**
```bash

```

```bash
  FILE_HASH=$(md5sum context/context-feedback.md 2>/dev/null | cut -d' ' -f1)

  if [ "$TEMPLATE_HASH" != "$FILE_HASH" ]; then
    # File has been modified - archive it regardless of entry count
    ARCHIVE_FILE="context/context-feedback-archive-$(date +%Y-%m-%d).md"
    cp context/context-feedback.md "$ARCHIVE_FILE"
    log_info "Archived modified feedback file to $ARCHIVE_FILE"
  fi
fi
```
