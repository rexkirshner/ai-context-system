**Status:** Final Revision - Focused & Modular
**Created:** 2025-10-20
**Target Release:** v2.2.0
**Timeline:** 10 days (not 25)

---

## Executive Summary

v2.2.0 is a **debt reduction and modularization release** based on 20+ sessions of real-world feedback. This release prioritizes:

1. 🔧 **Fix critical bugs** that cause real problems (git push, large files)
2. 🗑️ **Remove bloat** to reduce maintenance burden (-30% complexity)
3. 📦 **Modularize features** so components can be updated independently
4. 🤝 **Enable collaboration** through better documentation (not new features)
5. 🔒 **Add optional boundaries** for monorepos (plugin, not core)

**Key Principle:** Every change must reduce overall complexity or fix a proven problem.

### Priority 1: Fix Critical Bugs (Day 3-4)

**Why Second:** These cause real problems in every project.

#### Bug #1: Git Push Without Permission (10+ violations)

**Simple Fix - Add to ALL commands:**
```bash
# Before ANY git push
if [ "${PUSH_APPROVED:-false}" != "true" ]; then
  echo "❌ Git push requires explicit approval"
  echo "User must say: 'push', 'deploy', or 'push to github'"
  echo "Stopping here. Commit saved locally."
  exit 0
fi
```

**In `/review-context`:**
```bash
# Step 1: Set session flags
export PUSH_APPROVED=false
echo "⚠️ Git push protection: ENABLED"
```

#### Bug #2: Large SESSIONS.md Handling

**Simple Fix - Smart reading:**
```bash
# In /review-context
LINES=$(wc -l < SESSIONS.md)
if [ "$LINES" -gt 1000 ]; then
  # Read first 300 + last 500 lines only
  head -300 SESSIONS.md > temp_sessions.md
  tail -500 SESSIONS.md >> temp_sessions.md
  # Use temp_sessions.md instead
fi
```

#### Bug #3: Context Folder Detection

**Simple Fix - Check parent directories:**
```bash
# Function added to all commands
find_context() {
  for dir in "context" "../context" "../../context"; do
    [ -d "$dir" ] && echo "$dir" && return 0
  done
  echo "Error: context/ not found" >&2
  return 1
}
CONTEXT_DIR=$(find_context)
```

**Success Metric:** Zero git push violations, zero large file timeouts.

### Priority 3: Simple Boundary System (Day 7)

**Why Fourth:** Important for monorepos but should be optional.

#### Simplified Boundary Implementation

**NOT a complex bash script system!**

**Instead, simple config check in commands:**
```bash
# In each command, add ONE check
BOUNDARY_ENABLED=$(jq -r '.boundary.enabled // false' config.json)
if [ "$BOUNDARY_ENABLED" = "true" ]; then
  PROJECT_ROOT=$(jq -r '.boundary.root // "."' config.json)
  # Simple check: are we in PROJECT_ROOT?
  if [[ "$PWD" != "$PROJECT_ROOT"* ]]; then
    echo "⚠️ Outside project boundary. Returning to $PROJECT_ROOT"
    cd "$PROJECT_ROOT"
  fi
fi
```

**Config (opt-in):**
```json
{
  "boundary": {
    "enabled": false,  // Disabled by default
    "root": "./services/api"
  }
}
```

**That's it!** No complex scripts, no 600-line boundary checker. Just a simple path check.
